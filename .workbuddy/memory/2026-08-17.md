## Live2D 站娘（fuwari 主题）两处修复

文件：`src/features/theme/themes/fuwari/components/effects/live2d-widget.tsx`

1. **人物显示不全（裁剪）**：根因是 `anchor:[0,0]` + `position:[0,0]` 把模型矩形包围盒的左上角钉在舞台左上角，而 pixi-live2d-display 中模型的局部原点在中心，导致人物大部分跑到舞台外被裁掉。
   - 改为 `anchor:[0.5,0.5]` + `position` 取舞台中心，并把舞台固定为更大的盒子（`stageStyle` 380×380 桌面 / 300×300 移动），模型 scale 0.05 / mobileScale 0.035 不变。
   - 注意：`model3.json` 没有 Cubism `Layout` 段，故用“固定大舞台 + 居中”绕开包围盒偏小的问题。

2. **“关于”按钮改成“对话”按钮**：用 oml2d 的 `menus.items` 函数，过滤掉默认 `About` 项，追加自定义 `Dialogue` 项，点击随机弹一条 `tipsMessage(line, 5000, 4)`。
   - oml2d 内置图标没有“对话”图标，新增 `ensureChatIcon()` 向 body 注入 `<symbol id="icon-chat">`，按钮 `icon:"icon-chat"`。

验证：`tsc --noEmit` 与 `biome check` 均通过。删除了临时截图测试目录 `public/oml2d-test`。
注意：oh-my-live2d 未从包根导出 `Item` 类型（只在内部 common.d.ts），menu 回调参数类型靠上下文推断，不要显式 import `Item`。

## 二次修复（上午）

文件：`live2d-widget.tsx` + `pages/welcome/page.tsx`

1. **脑袋上方被裁（高度不够）**：把固定舞台高度从 380→520（桌面）、300→300→420（移动）。
   - 仍用 `anchor:[0.5,0.5]` + 居中 `position`（取 STAGE_SIZE 中心，无需改 position 行）。
   - 原理：无 Layout 段导致模型"报告中心"偏低、脑袋探出包围盒上沿；加高舞台给头顶留白即可。
   - 若脑袋仍贴顶，调 `STAGE_SIZE.height` / `MOBILE_STAGE_SIZE.height` 这两个数字。
2. **欢迎页不想显示站娘**：欢迎页 `WelcomePage` 在 `PublicLayout` 之外独立渲染，但 widget 是挂 `document.body` 的模块级单例，普通页初始化后会残留在欢迎页。
   - 新增导出 `setLive2dVisible(visible)`：给 `body` 加/去 `oml2d-hidden-welcome` class，并首次调用时注入一条 CSS（隐藏 `.oml2d-stage/.oml2d-menus/.oml2d-tips/.oml2d-statusBar`，`display:none!important`）。
   - welcome page 用 `useEffect` 挂载时 `setLive2dVisible(false)`、卸载时 `setLive2dVisible(true)`。
   - 用 CSS class 而非直接操作元素：能覆盖懒创建的 tips 等，离开即恢复。
   - oml2d 实例无公开 `show()/hide()`；四个部件 class 已在 dist 确认（stage:6268 / statusBar / tips / menus）。
