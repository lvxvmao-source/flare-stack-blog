# 2026-10-12 性能诊断：登录卡顿 + 浏览卡顿

## 现象
用户反馈站点最近出现「登录卡顿」与「浏览卡顿」（https://wavesand.de5.net）。

- 边缘节点固定 **SEA（西雅图）**，中国大陆访问跨太平洋往返。
- 所有静态资源响应头为 `public, max-age=0, must-revalidate`（浏览器每次必须回源校验）。

## 根因
### 浏览卡顿
1. **静态资源缓存策略错误** —— 内容哈希文件却要求每次 revalidate。最高性价比修复点。
2. **首屏 JS 2 MB** —— 检测到客户端主包含 `better-auth`、`drizzle`、`prosemirror`、`tiptap`；来源为 `vite.config.ts` 的 `tanstackStart({ importProtection: { enabled: false } })`，服务端库泄漏进客户端。
3. **中文字体重复加载** —— 每主题 CSS 228 条 `@font-face`（`src/features/theme/themes/*/styles/index.css` 引入 3 个 fontsource 变量字体，共 222 个 woff2 / 10.37 MB）；`src/routes/__root.tsx:59-72` 另从 Google Fonts 加载 ZCOOL XiaoWei / Ma Shan Zheng / Noto Sans SC，是渲染阻塞样式表。
4. **Live2D 31 MB 且默认开** —— `public/live2d/miku/`：moc3 9.07 MB + 6 张贴图约 21 MB（未压缩 PNG）。`src/blog.config.ts:36` `live2dEnabled: true`。
5. **SakuraPetals 全屏 canvas 每帧重绘** —— `sakura-petals.tsx` 每帧 `clearRect` 整屏 + 对 28~84 个花瓣逐个 `beginPath` + 5×`quadraticCurveTo` + 每帧解析 `oklch(...)` 字符串；`blog.config.ts:29` `sakuraEnabled: true`。与 Live2D 的 WebGL 循环并存。

### 登录卡顿
1. `/api/auth/get-session` 自身耗时 0.3–1.1 s，导航栏依赖 `isSessionLoading`，每次导航都等。
2. `/login` SSR 2.8 s。
3. 密码校验走 Durable Object：`src/lib/do/password-hasher.ts` scrypt `N=16384, r=16, p=1, dkLen=64`（maxmem ≈67 MB）；`src/lib/auth/auth.server.ts:40-45` 固定 10 个 DO 实例池随机选取。Worker→DO 往返 + DO 冷启动。
4. 登录页继承全部前端负担。

## 修复方案（待用户确认后实施）
- **P0**：`/assets/*`、`/live2d/*` 加 `max-age=31536000, immutable`；移除 Google Fonts 远程加载；Live2D 贴图转 WebP/AVIF 并改为空闲加载；花瓣动画默认关或桌面限定。
- **P1**：恢复 `importProtection` 并把 drizzle/better-auth/TipTap 移出主包（编辑器仅 /admin 懒加载）；花瓣改离屏位图 + `document.hidden` 暂停；字体瘦身；`get-session` 加短 TTL 缓存。
- **P2**：下调 scrypt 参数（需权衡安全）、给 PasswordHasher 设 `locationHint`、评估边缘节点线路。

### 1. `public/_headers`（新增）— 静态资源长缓存
- 根因定位：`node_modules/@cloudflare/vite-plugin/dist/workers/asset-worker/index.js:5012`
  `const CACHE_CONTROL_BROWSER = "public, max-age=0, must-revalidate";`（:5085 处使用）
- 方案依据：Cloudflare 官方文档 workers/static-assets/headers —— assets 目录中的 `_headers` 文件可覆盖默认响应头，且**不会应用于 Worker 代码生成的响应**
- 规则：`/assets/*` → `public, max-age=31536000, immutable`；`/live2d/*` → `86400`（模型文件名固定，折中 1 天便于换模型）；`/images/*` → `604800`；站点图标 → `86400`/`604800`
- **生效前提已核实**：`dist/server/wrangler.json` → `"assets":{"directory":"../client"}`，**无 `run_worker_first`** ⇒ assets 优先，`/assets/*` 等不经 Worker 代码 ⇒ `_headers` 生效
- 构建后 `dist/client/_headers`（1542 B）已生成
- ⚠️ 注意：`_headers` 对 Worker 生成的响应无效。若日后给 assets 配 `run_worker_first`，需改为在 Worker 里 `Response` 加头

### 2. `src/routes/__root.tsx` — Google Fonts 改异步
- ⚠️ **不能直接删**：ZCOOL XiaoWei / Ma Shan Zheng 被 `archive-year.tsx:12`、`footer.tsx:23` 内联使用，`welcome/page.tsx:15-17` 作为可配置字体
- 改法：删除 head.links 中的阻塞 `<link rel="stylesheet">`，新增常量 `ASYNC_FONT_SCRIPT`，在 `<body>` 开头以 `dangerouslySetInnerHTML` 注入；脚本用 `media="print"` 建 link，`onload` 后切 `media="all"`，失败静默
- preconnect 保留

### 3. `sakura-petals.tsx` — 离屏预渲染 + 不可见暂停
- 新增 `createPetalSprite()`（SPRITE_SIZE 64 / SPRITE_RADIUS 40），花瓣形状只绘制一次
- 每帧 `drawImage` 替代「重建 5 段 quadraticCurveTo + 每帧解析 oklch 字符串」
- alpha 复现原双重乘法：`Math.max(0.15, opacity) * opacity`
- 新增 `visibilitychange` + `document.hidden` 判断，隐藏时 `cancelAnimationFrame` 并停止排队
