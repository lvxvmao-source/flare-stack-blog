## 关键经验
1. **bun i18n:compile 在 Windows 上 segfault 崩溃**，用 `npx @inlang/paraglide-js compile` 替代成功
2. `anime-onload` 与 `anime-breathe` 都控制 animation 属性且前者覆盖后者 → 必须用外层 div 包裹结构分层
3. Vite dev 的 paraglide watch 插件报 SAFE_DELETE_BULK_CONFIRM_REQUIRED（沙箱保护阻止批量删除 src/paraglide），不影响已编译产物
4. 本地 D1（.wrangler/state）system_config 表为空时走 blog.config.ts 默认 themeName=default，导致 / 重定向 /home；插入 `{"site":{"themeName":"fuwari"}}` 即可预览欢迎页
5. D1 binding 名为 `DB`（wrangler.jsonc），查询用 `bunx wrangler d1 execute DB --local`
